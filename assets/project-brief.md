# 项目约定

在逐轮访谈后填写，未知标明影响与后续验证，不保留空表冒充完成。

- 真实目标与当前痛点：
- 谁使用、谁付费、谁处理后台业务：
- 首版核心闭环及成功条件：
- 已有项目/参考资料及只读范围：
- 输出或允许修改的目录：
- 首版启用模块 / 明确不包含：
- 身份、服务对象、家庭/组织/门店与权限：
- 支付或线下登记、权益与金额口径：
- 单企业独立部署 / 共享多租户：
- 预计活跃量、写入并发、附件/AI负载：
- 可接受的数据丢失窗口与恢复时间：
- 年度基础设施预算、云平台约束：
- 视觉方向、设备与无障碍需求：
- 现有AppID、主体材料、环境与发布阶段：
- 关键决策：反方依据 / 支持依据 / 证据裁决 / 推荐 / 反转条件：
- 待确认：阻塞哪个步骤、由谁提供：
- 各端完成标准、验收方式与证据：

需求变化时仅更新受影响部分，并同步相关功能契约与验收项。
