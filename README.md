# 小程序与中控搭建助手

根据行业和角色需求，协助搭建微信小程序、中控后台与服务端的 Codex Skill。经验提炼自会员型 AI 工具与门店服务项目，按新项目选择功能、视觉和技术方案。

## 核心方法

- **一次只问一个问题**：根据回答继续追问，理解目标、角色和核心流程后再给方案。“95%”表示理解充分，不是虚构的概率。
- **重要决策做压力测试**：先找最有力的反对依据，再分析支持理由，最后按证据给明确推荐、最大未知与反转条件。反对意见配替代方向或验证办法，不强行五五开。
- **按业务闭环开发**：连接小程序、后台与服务端，覆盖权限、数据归属、异常恢复和两端验收。
- **区分验收层级**：代码、模拟器、浏览器、云端、真机与平台审核分别记录，不把打包成功当作上线。

## 安装与使用

1. 从本仓库 Releases 下载 miniapp-console-builder.zip 并解压。
2. 将完整的 miniapp-console-builder 文件夹放入 Codex 的 skills 目录（默认 ~/.codex/skills/），保留全部子目录。
3. 新开对话，确认技能已被识别，然后输入：

```text
使用 $miniapp-console-builder，我想做一个宠物预约小程序和管理后台。请先一次问我一个问题，理解需求后再给方案。
```

其他支持 SKILL.md 的工具可按各自的技能导入方式安装；执行能力取决于宿主工具。

## 文件结构

- SKILL.md：执行入口与分阶段流程。
- references/：访谈、决策、架构、业务模块、交互和发布指南。
- assets/：项目约定、功能契约、白名单示例及网络参考组件。
- scripts/：只读预检、精确白名单打包与隔离测试。
- agents/：Codex 界面元数据。

## 验证与边界

当前版本通过 Skill 结构校验、14 项 Python 工具测试及10项 Node 参考组件测试；另外完成两个非口腔场景的人工流程推演。尚未使用本 Skill 完整交付新的应用。

需要 Python 3.10+ 和支持 node:test 的 Node.js 才能运行配套测试：

```sh
PYTHONDONTWRITEBYTECODE=1 python3 scripts/test_tools.py
node scripts/test_network.js
```

本 Skill 不包含原项目账号、密钥、客户资料或品牌素材，不依赖原项目目录。实际项目仍需自备开发工具和云资源，并完成真机验收及平台审核。静态预检不等于完整安全审计。
